# 17: Verify and ship the MVP

**What to build:** Verify the complete survival loop in supported desktop browsers, finish the approved presentation and ship the static build on Vercel.

**Blocked by:** 10 — Navigate with the minimap and full map, 14 — Continue an encounter in progress, 15 — Recover from ownership and revision conflicts, 16 — Recover from unreadable or damaged saves

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Play through both survivor openings, both House B approaches, the House C trip, inventory actions, combat, save and Continue, death and restart using normal desktop controls.
- [ ] Exercise the PRD release acceptance cases, including cautious detour pacing, House A’s later zombie visit, muted combat cues and guarded save recovery.
- [ ] Compare each shipped screen to its matching approved spec and reference. Verify readable UI and animation at the documented sizes and gameplay zoom, and test the target scene with 20 active zombies.
- [ ] Run the production build and check the static Vercel release in supported desktop browsers. Verify the shipped site can complete the full playable loop and Continue a local save.
