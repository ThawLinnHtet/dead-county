# 08: Scavenge House C

**What to build:** Explore the complete authored neighborhood and choose whether to risk a run to House C for dependable essentials.

**Blocked by:** 07 — Make the first supply run to House B

**Status:** ready-for-agent

## Acceptance criteria

- [ ] One continuous neighborhood contains exactly three enterable single-floor houses with readable routes, open entrances and the approved roof treatment.
- [ ] Each fresh run gives House C at least one Canned Food and one Water Bottle in reachable ordinary loot containers. Both can be transferred through normal inventory rules.
- [ ] The authored start contains 10–20 ordinary zombies using the same gameplay archetype across five visual variants. Both survivors share starting positions, wander destinations and loot configuration.
- [ ] House C’s exposure and approach create greater encounter pressure through normal placement, perception and pursuit. Verify House A’s starter path still offers a combat-free opportunity.
